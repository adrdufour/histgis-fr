# Le recensement de 1968 — ce que les fascicules contiennent

Mesuré le 15 août 2026, sur les 83 fascicules déposés sous `sources/rp1968/`.
Index : `cog1968/index_fascicules.py` → `fascicules_1968.csv`.

---

## En un mot

**1968 est plus facile que 1954, et d'un cran, pas d'une nuance.** Le tableau
III porte le **code INSEE de la commune**. Là où 1954 obligeait à apparier
38 000 noms — et en laissait 7 576 sur le carreau — 1968 donne la clé de
jointure directement.

## Ce qui est dans les fichiers

83 fascicules, 636 Mo, un par département. **83 départements sur 95.**

**Douze manquent** : Aude (11), Orne (61), Pas-de-Calais (62), Saône-et-Loire

### La couche texte : les liminaires oui, les tableaux non

Chaque PDF porte un texte partiel — de 10 000 à 14 000 caractères pour une
trentaine de pages, soit environ 400 par page, ce qui est un ordre de grandeur
en dessous d'un tableau de communes. La mesure page par page le confirme : les
liminaires sont lisibles, **les pages de tableaux sont à zéro caractère**.

Utile quand même : le département se lit sans OCR, ce qui a permis l'index.

## La structure du tableau III

Une ligne par commune, dans cet ordre :

```
[pop. 1962] [pop. 1962 sans doubles] [arr] [canton] [code INSEE] Nom.  [pop. 1968] …
```

Exemple lu sur la page 21 du fascicule de l'Aisne :

```
219  219   4  35  562  Nouvron-Vingré.   221  221  124  97  …
215  215   5  16  563  Noyales.          185  185  154  31  …
321  321   4  31  564  Noyant-et-Aconin. 367  367  359   8  …
```

**Le nombre à trois chiffres est le code INSEE de la commune** — vérifié sur
neuf communes prises au hasard, **9 concordances sur 9** avec `noms_geofla`.
C'est cohérent : les codes INSEE sont attribués dans l'ordre alphabétique, et
la colonne progresse alphabétiquement.

### Quatre garde-fous que 1954 n'offrait pas

| | |
|---|---|
| **le code INSEE** | plus d'appariement par nom, donc plus de 7 576 orphelins |
| **le code INSEE croît** | monotone dans la page : un chiffre mal lu se détecte sur ses voisins |
| **le tableau II** | population **et nombre de communes** par canton — une recette de contrôle fournie par la source |
| **l'en-tête de page** | « AISNE (02) » sur chaque page de tableau : le département ET son code, à chaque feuille |

Le dernier point vaut d'être noté : l'index par page de titre a demandé trois
essais et une correction manuelle. L'en-tête des pages de tableau aurait donné
la réponse directement, avec le code numérique en prime. **La bonne clé était
sur la page suivante.**

## La mesure de faisabilité

Une page OCRisée, comparée à la composition cantonale de 1940 déjà en base.

| | |
|---|---|
| lignes lues sur la page | 39 |
| **canton conforme à 1940** | **31 — 79 %** |
| divergent | 8 |
| commune absente de la base | 0 |

**Et ce chiffre est un plancher, pour trois raisons.** L'OCR a tourné en
**anglais**, faute du paquet `tesseract-ocr-fra` dans le bac à sable. Aucune
des corrections écrites pour 1954 n'a été appliquée — ni la table des sosies,
ni le contrôle de monotonie, ni le redécoupage. Et le rendu était brut, sans
prétraitement.

### Les huit divergences

```
02568 OIGNY-EN-VALOIS   lu 0216   base 0236
02569 OISY              lu 0287   base 0237
02576 OSLY-COURTIL      lu 0285   base 0235
02607 PLOISY            lu 0281   base 0231
02608 PLOMION           lu 0284   base 0234
```

Le motif saute aux yeux : **le 3 initial est lu 8, 2 ou 1**. Sept divergences
sur huit portent sur ce seul chiffre.

**Mais attention, et c'est la leçon de 1954** : un transfert réel de commune
entre 1940 et 1968 produirait exactement la même trace. Le motif rend
l'explication par l'OCR très probable ; il ne la prouve pas. Les 311
« transferts » de 1954 avaient tous des codes valides et des cantons réels, et
la géométrie en a réfuté 227. **Ne pas conclure sur un motif : mesurer sur un
département entier, avec le tableau II comme arbitre.**

## Ce qu'il reste à faire, dans l'ordre

1. **Installer `tesseract-ocr-fra`** et refaire la même page. C'est la
   variable à changer seule, avant toute autre — sans quoi on ne saura pas à
   quoi attribuer le gain.
2. Écrire `cog1968/extrait_1968.py`. La chaîne de 1954 se réutilise ;
   l'appariement par nom disparaît, la lecture du code INSEE le remplace.
3. **Extraire le tableau II** — le nombre de communes par canton. C'est la
   recette de contrôle que la source fournit, et 1954 ne l'avait pas.
4. Passer l'Aisne en entier, la confronter à 1940 et à 1954. Trois dates sur
   le même département, dont deux déjà validées.
5. Puis les 82 autres, et retélécharger les douze manquants.

## Rappel de portée

1968 est **un jalon daté à l'intérieur du trou 1941-1998**, pas le trou comblé.
Il donne la carte cantonale à une date, entre 1954 et 1999. Les décrets du JO
(`cantons/composition_decrets.py`) donnent les mouvements entre les jalons. Ni
l'un ni l'autre ne couvre 1987-1998, où l'annexe VII s'arrête et où le COG ne
recense que 66 changements, tous postérieurs à 1995.
